Алгоритм генерации ключей (Эль-Гамаль):
1. Выбрать простое число p
2. Найти все первообразные корни g (gφ(p) = 1 mod p, gl ≠ 1 при 1 ≤ l ≤ φ(p)−1)
3. Выбрать закрытый ключ x ∈ (1, p−1)
4. Вычислить y = gx mod p

Алгоритм шифрования (побайтово):
Для каждого байта m: выбрать k взаимно простое с p−1  →  a = gk mod p,   b = yk·m mod p
Первый блок шифруется введённым k, остальные — случайными k.
p должно быть > 255 для шифрования любых файлов.
